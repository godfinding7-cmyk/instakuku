How InstaKuku works.

A transparent explanation of the workflow, limitations and safe-use rules.

Important: the tool is for public Instagram Reels you own or have permission to save. It is not designed to bypass private-account controls.

1. You provide a public Reel URL

The server validates that the link points to an Instagram Reel path. Links to unrelated hosts, private-only pages or unsupported Instagram areas are rejected before analysis.

2. The server reads available public media information

The backend uses yt-dlp to request metadata and publicly available media formats. It does not ask for your Instagram password and this starter project does not use account cookies.

3. You choose an available format

If Instagram exposes a downloadable progressive video format, the interface can show the resolution and estimated file size. Actual options vary by Reel and can change when Instagram changes its delivery system.

4. The file is prepared temporarily

The backend downloads the selected public media to a temporary server folder, sends it to the visitor, and then removes the temporary file. Hosting providers can impose their own bandwidth, disk and execution limits.

Why a Reel can fail

Common reasons include a private account, deleted or region-restricted content, temporary anti-bot limits, an Instagram delivery change, or server-side network restrictions.

What this does not do

It does not unlock private Reels, circumvent passwords, remove watermarks from third-party content, or grant permission to repost copyrighted material.
